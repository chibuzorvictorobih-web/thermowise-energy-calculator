THERMOWISE 2.0 — FINAL PACKAGE
====================================

THIS IS ONE COMPLETE PROJECT FOLDER. YOU DO NOT NEED TO COMBINE IT
WITH ANY EARLIER THERMOWISE ZIP FILES.

QUICKEST WAY TO OPEN IT ON YOUR WINDOWS LAPTOP
------------------------------------------------
1. Extract the ZIP into a normal folder.
2. Open the extracted 'ThermoWise_2.0_FINAL' folder.
3. Double-click RUN_THERMOWISE_WINDOWS.bat.
4. Wait for the tests and dependencies (internet may be needed).
5. Open http://localhost:8501 in Chrome when Streamlit starts.
6. Select the fifth tab, 'Decentralised System'.
7. Click 'Run Hourly Energy Simulation'.

The 4 older tabs are also present.

IF WINDOWS BLOCKS THE .BAT FILE
--------------------------------
Open VS Code > Terminal > New Terminal in this extracted folder.
Run these commands individually:

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py" -v
.\.venv\Scripts\python.exe -m streamlit run app.py

If 'py' does not work, use 'python' in the first line.
Do not double-click app.py itself.
